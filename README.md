# StreamFlix FEWD — Interactive Netflix-Style Upgrade

A React + Vite streaming-platform prototype for a FEWD project.

## Added in this upgrade
- Netflix-style top navigation with search beside the profile
- Live search suggestions and related-title results
- 40+ movie/series options including popular demo titles
- Trending, Popular, Top 10, Continue Watching and Recommended rows
- Because You Watched recommendations based on watch history
- My List with localStorage persistence
- Watch Later with localStorage persistence
- Continue Watching with progress indicators
- Movie details modal with similar titles
- Individual demo preview video for every featured series/movie entry
- Smooth horizontal rows and responsive UI
- Profile menu with quick navigation
- Hero carousel with Play, More Info and Watch Later
- Search + genre + sorting controls
- Toast feedback and keyboard Escape controls

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The demo videos in `public/videos/` are lightweight locally generated title-card previews, so the project does not depend on third-party video hosting for the demo player.
